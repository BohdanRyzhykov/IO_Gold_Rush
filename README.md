# ⛏️ Gold Digger

A simple **Java game** created as a university project.

## 🎮 About

The player controls a miner and collects gold while avoiding obstacles.
The goal is to collect as much gold as possible and achieve a high score.

## ✨ Features

* 🧑‍🏭 Player movement
* 🪙 Gold collection
* 🏆 Score system
* 🪨 Obstacles and collisions
* 🔄 Game over and restart

## 🛠️ Technologies

* ☕ Java
* 🖼️ Java Swing
* 🧩 Object-Oriented Programming (OOP)

## 🎓 Purpose

This project was created to practice **Java, OOP, game logic, and GUI development**.
